# Веб ларёк на Express
**стек:** TypeScript, Express, MongoDB, Mongoose, JWT

реализован backend на Express для практики в применении Express, роутов, контроллеров и миддлвар, а также для практики заимодействия с MongoDB.
- Проект реализован по REST API.
- Реализовано хранение данных в MongoDB
- Реализован доступ к эндпоинтам только авторизованным пользователям

## Запуск проекта
```sh
cd ./frontend
npm i
npm run dev
cd ./backend
npm i
npm run dev
```
